# FreeAds — Components Style Guide

## 1. Buttons

### Primary Button (Blue)
- Background: #1A73E8  
- Text: #FFFFFF  
- Border-radius: 8px  
- Padding: 12px 20px  
- Font-weight: 500  

### CTA Button (Orange)
- Background: #FF6F3C  
- Text: #FFFFFF  
- Use only for the most important action on a page.

### Secondary Button (White)
- Background: #FFFFFF  
- Border: 1px solid #E5E7EB  
- Text: #1E1E1E  
- Hover: light grey background

### Disabled State
- Opacity: 40%  
- Cursor: not-allowed  

---

## 2. Inputs & Forms
- Background: #FFFFFF  
- Border: 1px solid #E5E7EB  
- Border-radius: 6px  
- Padding: 10px–14px  
- Focus: border-color changes to #1A73E8  
- Error: border-color changes to #DC3545  

---

## 3. Announcement Cards
- Background: #FFFFFF  
- Border-radius: 10px  
- Box-shadow: subtle (0 2px 6px rgba(0,0,0,0.05))  
- Padding: 16px  
- Image ratio: **4:3**  
- Title: Inter SemiBold 18px  
- Price: Inter Bold 20px, color #1A73E8  
- Location: small text grey (#4A4A4A)

---

## 4. Header
- Background: #FFFFFF  
- Shadow: 0 2px 4px rgba(0,0,0,0.04)  
- Height: 70px  
- Always fixed at the top  
- Contains search bar + logo + account menu

---

## 5. Filters Sidebar
- Width: 250px  
- Background: #FFFFFF  
- Border-right: 1px solid #E5E7EB  
- Sections spaced by 24px  
- Inputs identical to form styles  

---

## 6. Footer
- Minimalistic  
- Background: #F5F7FA  
- Text color: #4A4A4A  
- Height: 80–120px
