# FreeAds — Design System Summary

## Colors
- Primary: #1A73E8  
- CTA: #FF6F3C  
- Background: #F5F7FA  
- Text: #1E1E1E / #4A4A4A  
- Borders: #E5E7EB  

## Typography
- Inter as main font  
- Optional titles in Poppins  
- Clear hierarchy: H1 32px → body 16px  

## Components
- Buttons: blue primary, orange CTA  
- Cards: white, soft shadow, 4:3 image  
- Inputs: white, 1px grey border, blue focus  
- Sidebar filters with clean spacing  

## Layout
- Fixed header with search bar  
- 3-column desktop layout  
- Mobile-first responsiveness  
- 8px spacing scale  

## Consistency Checklist
- Use the defined color palette only  
- Keep typography hierarchy unchanged  
- Maintain consistent padding and radius  
- Avoid decorative elements that break minimalism  
- All CTAs should use the orange button  
- Ensure contrast ratios are respected  
- Keep icons simple and monochromatic
