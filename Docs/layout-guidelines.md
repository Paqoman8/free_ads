# FreeAds — Layout Guidelines

## 1. Grid System
- Desktop: 3-column layout  
  - Left: Filters (250px fixed)
  - Center: Ads (2–3 columns depending on screen)
  - Right: Optional space or empty

- Mobile:
  - Filters collapse into an accordion
  - Ads become 1 column

## 2. Spacing Scale (8px base)
- 4px — Micro spacing
- 8px — Base spacing
- 16px — Standard spacing (most used)
- 24px — Section spacing
- 32px — Large spacing (titles, large blocks)

## 3. Breakpoints
- Mobile: < 640px  
- Tablet: 641px–1024px  
- Desktop: > 1024px
