# FreeAds — Color Palette

This palette is designed for clarity, trust, and functional UI interactions.

## 1. Main Colors

| Role             | Name              | HEX     | RGB           | Usage                       |
| ---------------- | ----------------- | ------- | ------------- | --------------------------- |
| Primary          | Blue Trust        | #1A73E8 | 26, 115, 232  | Buttons, links, highlights  |
| Secondary CTA    | Orange Action     | #FF6F3C | 255, 111, 60  | CTAs, “Post an ad”, accents |
| Background Light | Light Grey        | #F5F7FA | 245, 247, 250 | Page background             |
| Cards            | White             | #FFFFFF | 255, 255, 255 | Cards, containers           |
| Text Title       | Dark Grey         | #1E1E1E | 30, 30, 30    | Titles                      |
| Text Paragraph   | Medium Grey       | #4A4A4A | 74, 74, 74    | Body text                   |
| Borders          | Light Border Grey | #E5E7EB | 229, 231, 235 | Borders, dividers           |
| Success          | Green Success     | #4CAF50 | 76, 175, 80   | Success badges              |
| Error            | Red Error         | #DC3545 | 220, 53, 69   | Errors, warnings            |

## 2. Color Usage Guidelines
- Use **blue** for all primary actions (links, main buttons).
- Use **orange** only for important CTAs (e.g., "Post an Ad").
- Background must stay **very light** to enhance clarity.
- Avoid using too many colors in the UI—maintain a clean, readable look.
- Always use **Dark Grey (#1E1E1E)** for titles for maximum contrast.

## 3. Accessibility Notes
- Main text contrast:  
  - Dark Grey (#1E1E1E) on Light Grey (#F5F7FA) → WCAG AA compliant.
- Buttons must maintain at least 4.5:1 contrast ratio.
- Avoid using orange for text due to lower contrast.

## 4. Colors to Avoid
- Highly saturated neon colors  
- Pure black (#000000) for text (too harsh)  
- Overuse of orange (reduces the focus effect)

## 5. Palette Summary
A modern, clean palette focused on trust (blue), dynamics (orange), and neutrality (greys).
