# FreeAds — Typography Guidelines

## 1. Primary Font
**Inter**  
- Modern, geometric sans serif  
- Excellent readability on web interfaces  
- Optimized for UI, dashboards, product listings

## 2. Secondary Font (Optional)
**Poppins** (for headers only)  
- Rounded and friendly tone  
- Use sparingly to avoid visual noise

## 3. Font Weights
- 900 → Heavy (rarely used)
- 700 → Bold (titles, emphasised UI)
- 600 → SemiBold (subtitles, card titles)
- 500 → Medium (buttons)
- 400 → Regular (body text)
- 300 → Light (optional for secondary text)

## 4. Recommended Font Sizes

| Element        | Size | Weight | Line Height |
| -------------- | ---- | ------ | ----------- |
| H1             | 32px | 700    | 1.2         |
| H2             | 28px | 600    | 1.3         |
| H3             | 22px | 600    | 1.3         |
| H4             | 18px | 600    | 1.4         |
| Body (regular) | 16px | 400    | 1.5         |
| Small text     | 14px | 400    | 1.4         |
| Buttons        | 16px | 500    | 1.4         |
| Inputs         | 16px | 400    | 1.4         |

## 5. General Rules
- Use **Inter Regular** as the default for all content.
- Titles should always be SemiBold or Bold.
- Avoid mixing too many font sizes.
- Maintain at least 4px–8px spacing between text blocks.

## 6. Why these fonts work
- High readability on mobile and desktop.
- Clean, professional, and modern look fitting a marketplace.
- Works well with long lists and content-heavy pages.
